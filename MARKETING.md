## Announcement draft

**Title**

I built SubCycler, an open-source Android tracker for rotating streaming subscriptions

**Post**

I wanted a way to remember when to pause a streaming subscription and when to pick it back up. SubCycler tracks recurring bills and helps me plan 30 days of paid access followed by a 15-day break. It sends renewal reminders and links to official billing pages so I can handle changes directly.

It's built with Kotlin, Jetpack Compose, and Room. There’s no SubCycler account to set up. I'd like feedback on whether the rotation planner and cancellation links are clear. If you build Android apps, there are a few small issues you can turn into a first PR.

- [Source and build instructions](https://github.com/SafalFrom2050/SubCycler)
- [Good first issues](https://github.com/SafalFrom2050/SubCycler/contribute)

## Sharing the launch

1. Share a short demo of creating a 45-day plan in an Android app community that accepts project posts. Ask whether people understand what they'll need to do before the next renewal.
2. Share the contributor link in a Kotlin or Jetpack Compose project-sharing thread. Point to one specific starter issue with a test or reproduction.
3. When a signed preview APK is ready, add it to [GitHub Releases](https://github.com/SafalFrom2050/SubCycler/releases) and link to it from the README so people can try the app without a build environment.
